description: 事物本身——代码、对话记录、原始数据。完整权威，但载入 context 成本高。
---

一手来源（primary source）是以原始形态存在的真相来源——代码、对话记录（transcript）、原始日志、真实的 API 响应。不是对事物的描述；是事物本身。[secondary source](./Secondary%20source.md)（二手来源）的对应面。

想知道代码库做什么，代码就是一手来源。文档、架构图和 README 都是对它的描述——写成时准确，此后各按自己的节奏更新。当一个[agent](./Agent.md)（智能体）自信地断言关于你项目的错误说法，该问的是它依据哪个来源：读了文档的 agent 继承文档的过时；读了代码的 agent 读到的是当前真相。

成本是一手来源不能成为默认选项的原因。把它载入[context window](./Context%20window.md)（上下文窗口）很贵——整个文件、整份记录，每个[token](./Token.md)（词元）按[input](./Input%20tokens.md)（输入）计费，还要争夺[attention budget](./Attention%20budget.md)（注意力预算）。这笔成本换来的是完整性：没有被别人按"什么重要"的判断预先过滤过。上个月写的摘要装不下今天才显出重要的细节；一手来源仍带着它。

需要精确时取一手来源——确切签名、真实错误、抛出异常的那一行。管理[context](./Context.md)（上下文）的很大一部分，就是决定何时付一手来源的成本、何时二手来源够用。

_用法：_

"agent 说重试逻辑是指数退避，可我看着它在猛砸端点。"

"它从设计文档里读来的。让它去读真正的重试模块——行为要紧时，从一手来源工作。"
