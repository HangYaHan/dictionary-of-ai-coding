一个会移动的标签，不是技术。"AI" 不像 [model](./Model.md) 或 [token](./Token.md) 那样指一个固定事物——它指向计算机新近能做的、令人印象深刻的事。当下它指向大语言模型。它以前指向很不同的东西：

| 时代      | 当时 "AI" 意味着什么                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------- |
| 1950s     | 符号推理——定理证明器、西洋跳棋程序。                                                                  |
| 1960s–70s | 基于规则的符号程序——ELIZA、SHRDLU。                                                                    |
| 1980s     | 专家系统——数千条手写 if-then 规则编码人类专业知识。                                                   |
| 1990s     | 博弈树搜索——Deep Blue 击败 Kasparov（1997）。研究者完全避开 "AI" 一词                                 |
| 2000s     | 统计机器学习——垃圾邮件过滤、推荐系统。仍以 "machine learning" 而非 "AI" 销售                         |
| 2010s     | 深度学习——图像识别（AlexNet，2012）、AlphaGo（2016）。                                               |
| 2020s     | 大语言模型——ChatGPT（2022）让 "AI" 意味着聊天机器人                                                   |

这个指针按一个已知机制移动，常称为 AI effect：一项技术一旦可靠奏效，就被改名——"只是"搜索，"只是"统计——而 "AI" 滑向下一个未解决的东西。观察很早。Bertram Raphael 1971 年这样表述："AI 是我们尚不知如何用计算机妥善解决的问题的统称。" Larry Tesler 约 1979 年的版本："智能是机器还没做到的事。"

这就是关于 AI 的对话常常各说各话的原因。像 "AI 不能推理" 或 "AI 被过度炒作" 的主张带着隐藏时间戳——它可能关于专家系统、关于 2010 年代的图像分类器、或关于上个月的 LLM，而每个所指支撑不同结论。当关于 AI 的讨论卡住，修复通常是把该词换成本意的精确术语：model、[harness](./Harness.md)、[agent](./Agent.md)、给出的 [context](./Context.md)。

_避免：_任何技术主张里的 "AI"——改说你指的部件。"AI coding" 作为实践标签没问题；"the AI is hallucinating" 不行。

_用法：_

"CTO 想知道 AI 能否处理分诊队列。"

"先翻译再定范围——她的意思是一个带工单系统访问权的 harness 里的 LLM。'AI' 本身不是 spec。"
